# ComfyUI custom node 목록. 한 줄 = "<git-url> <commit-sha>" (공백 구분).
#
# ⚠️ **커밋 SHA 를 반드시 함께 적는다.**
#
# 예전에는 URL 만 나열했고 Dockerfile 이 `xargs -n 1 git clone --recursive` 로 받았다.
# 그러면 매 빌드가 그 시점의 upstream HEAD 를 받으므로 **같은 커밋으로 빌드해도 다른
# 이미지가 나온다.** 대가는 2026-09-23 에 실측했다: Windows TensorRT blob 2.07GB(비압축)를
# 지웠는데도 custom_nodes 레이어 합계가 6.000 → 7.256GB 로 오히려 늘었다. 2026-08-08 빌드
# 이후 6주치 upstream 드리프트가 그대로 유입된 결과이고, `.git` 만 759 → 923MB 였다.
# 회귀가 나도 어느 노드의 어느 커밋 때문인지 좁힐 방법이 없었다.
# (docker-bake.hcl 이 torch nightly 를 버리고 핀으로 돌아선 사유와 같은 문제다 —
#  "nightly made every rebuild a different torch, which made any regression
#   impossible to reproduce".)
#
# 아래 SHA 는 2026-09-23 검증 빌드(meshive/comfyui:base-torch2.8.0-cu128)에 **실제로
# 들어간 커밋**이다. 이미지 안에서 `git rev-parse HEAD` 로 뽑았으므로 핀과 검증된
# 바이트가 일치한다.
#
# 올릴 때:
#   1) `git ls-remote <url> HEAD` 로 upstream HEAD 확인
#   2) 해당 줄의 SHA 만 교체
#   3) 빌드 + GPU 검증
#   여러 줄을 한꺼번에 올리면 회귀 원인 좁히기가 어렵다 — 나눠서 올릴 것.
#
# `#` 로 시작하는 줄과 빈 줄은 무시된다. SHA 를 비우면 기본 브랜치 HEAD 를 받는다
# (재현성이 깨지므로 쓰지 말 것).
