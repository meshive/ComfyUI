# ComfyUI cu130 이미지의 **기반** pip 잠금 — Dockerfile 의 기반 패키지 RUN(jupyterlab·numpy·huggingface_hub
# 등 + torch 의 자유 의존성 sympy·networkx)이 까는 것만 담는다. 왜 따로 두는지는 Dockerfile 의
# PIP_BASE_LOCK_FILE 주석, 잠그는 이유는 constraints/cu130.txt 헤더.
#
# 무엇이 들어 있나: 그 RUN 의 패키지 목록을 constraints/cu130.txt 버전으로 해석한 의존성 전부(122개).
# 모든 줄이 constraints/cu130.txt 에 **같은 버전으로** 있어야 한다 — 다르면 기반 레이어에 한 버전을 깔고
# 뒤 단계가 다른 버전으로 다시 깔아 이미지에 두 벌이 들어간다(대조는 통과해도 바이트가 는다).

# 다시 만드는 법 (기반 RUN 목록을 바꾸거나 기반 패키지를 일부러 올릴 때만):
#   rc 이미지 안에서 새 venv 로, 전체 잠금을 constraint 로 준 dry-run 결과를 쓴다.
#     sed -E '/^[[:space:]]*(#|$)/d; / @ /d' constraints/cu130.txt > /tmp/c.txt
#     uv venv --seed /tmp/v && PIP_CONSTRAINT=/tmp/c.txt /tmp/v/bin/python -m pip install --dry-run \
#         --ignore-installed --report /tmp/r.json <기반 RUN 의 패키지 목록>
